# Storage Estimator - Feature Version
# 

# \## Description

# A simple Python program that calculates the total storage required for multiple files.

# 

# \## Requirements

# \- Python 3

# 

# \## How to Run

# 1\. Open a terminal in the project folder.

# 2\. Run `python storage\_estimator.py`.

# 3\. Enter the size of one file in MB.

# 4\. Enter the number of files.

# 

# \## Example

# \- File size: 500 MB

# \- Number of files: 10

# \- Total storage: 5000 MB

# \- Total storage in GB: 4.88
