# Storage Estimator

A simple Python program that estimates total storage for multiple files.

## How to Run
1. Install Python.
2. Run storage_estimator.py.
3. Enter the size of one file in MB.
4. Enter the number of files.

## Example
File size: 500 MB
Number of files: 10

Total storage in MB: 5000
Total storage in GB: 4.88
